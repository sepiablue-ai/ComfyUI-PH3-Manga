# ComfyUI-PH3-Manga

A ComfyUI custom node pack for drawing manga pages from character reference images, arranging speech balloons, and adding Japanese lettering in a workflow.

## What you can do

- **Pick a panel layout from preview images:** 196 blank layouts with 2–6 panels, filtered by panel count, type or name, with favorites. Picking one adds or removes scene nodes to match; removed panels are stashed and restored when the count goes back up.
- **Generate manga from up to three characters and per-panel content:** each scene node holds a scene (English) and the characters in that panel. The node pack builds the P-H3 prompt.
- **Edit dialogue, speakers, balloons, and tails in one place:** enter dialogue only once, move and resize balloons, and drag each tail tip with the mouse. The empty-balloon guide becomes an input to the generation model.
- **Add Japanese vertical lettering:** dialogue, explicit line breaks, ruby readings, vertical punctuation, basic line-start restrictions, and horizontal-in-vertical pairs such as `！？`. Kana and kanji can use different fonts.
- **Revise lettering while retaining the artwork:** use the separate lettering workflow with a saved unlettered PNG. That workflow contains no P-H3 nodes.

Lettering is rendered with fonts. Dialogue and ruby are not text generated by P-H3 or MOSS. The balloon guide is also an input drawing. It does not guarantee that P-H3 will reproduce balloon geometry or character appearance exactly.

## Installation

### 1. Prepare ComfyUI

Use a version of [ComfyUI](https://github.com/Comfy-Org/ComfyUI) with native P-H3-Image support. The generation example needs `PH3ImageConditioning` and `MiniMaxH3SigmaShift`. The existing-page lettering example uses `CreateBoundingBoxes`. If these nodes are missing, update ComfyUI after protecting your existing environment.

### 2. Install the node pack

Place this repository at `ComfyUI/custom_nodes/ComfyUI-PH3-Manga`. You do not need to install `ComfyUI-MossPanelDataset` separately.

Run this using **the Python environment that runs ComfyUI**, rather than installing into a system-wide Python environment:

```bash
python -m pip install -r ComfyUI/custom_nodes/ComfyUI-PH3-Manga/requirements.txt
```

If ComfyUI ships with its own Python, replace `python` with that executable. BudouX provides Japanese phrase segmentation. PyTorch, NumPy, and Pillow come from the ComfyUI environment.

### 3. Prepare a Japanese font

Place a Japanese font you are licensed to use in this pack's `fonts/` directory. Supported file types are `.ttf`, `.ttc`, `.otf`, and `.otc`. [Noto CJK](https://github.com/notofonts/noto-cjk) is one option. Fonts are not bundled.

Set `kana_font` and `kanji_font` to `auto` to search the pack's font directory and installed Japanese fonts. Installed Yu Mincho and Yu Gothic fonts are also candidates on Windows. For consistent typography across machines, explicitly select the same font filenames. `PH3_MANGA_FONT_DIR` adds another search directory.

### 4. Install P-H3 model files

For manga generation, obtain the models from [PrunaAI/P-H3-Image-Comfy](https://huggingface.co/PrunaAI/P-H3-Image-Comfy). The generation example selects these filenames:

| Component | Directory relative to ComfyUI | Filename |
|---|---|---|
| Diffusion model | `models/diffusion_models/` | `p-h3-image_int8_convrot.safetensors` |
| Text encoder | `models/text_encoders/` | `p-h3-image_text_encoder_int8_convrot.safetensors` |
| VAE | `models/vae/` | `p-h3-image_vae_int8_convrot.safetensors` |

To use another supported precision, select the corresponding files in the loaders. This example uses a standalone P-H3 model with the LoRA already incorporated and does not use a prompt upsampler. **Lettering an existing page does not require P-H3 model files.**

### 5. Restart and open a workflow

Restart ComfyUI, reload the browser, and drag a JSON from `example_workflows/` onto the canvas.

| Workflow | Purpose |
|---|---|
| [01_generate_and_letter.json](example_workflows/01_generate_and_letter.json) | Generate a three-panel manga page with empty balloons from two character references and scene descriptions, then add lettering |
| [02_letter_existing_page.json](example_workflows/02_letter_existing_page.json) | Add dialogue and ruby to a page you provide |

Character images and input pages are not bundled. Upload your own images in each `LoadImage` node.

If you already use the previous unified editor, save any inputs you need, hard-reload the browser with `Ctrl+F5`, and open the updated `01_generate_and_letter.json`. Generation and dialogue-only revision now use separate workflows.

## Usage

### Generate, then letter

The workflow has three groups: inputs, P-H3 generation, and saved artwork/lettering. The editor's controls use Japanese labels.

1. Upload the character references. For a third character, add a `LoadImage` and connect it to `人物3` on `PH3MangaStory` (only when character 2 is connected).
2. On **漫画の編集** (`PH3MangaBalloonEditor`), click **画像からコマ割りを選ぶ** to choose a layout. Scene nodes are added or removed to match.
3. Fill in each `PH3MangaScene`: `場面` is the scene in English; `登場人物` selects the characters. Write `人物1`/`人物2`/`人物3` in the scene and they become `the character from <Picture N>`. Scene nodes do not contain dialogue fields.
   - Objects with a strong color association, such as bread, may come out colored even on a black-and-white page. Adding "black and white" to the whole page or to every panel did not prevent it. Describe the object's monochrome look in the scene itself, for example `a croissant drawn as a plain white shape with black ink outlines and light gray screentone` (with a croissant, this removed the color on both seeds tested).
4. Open the balloon editor on that node. Set each balloon's panel, speaker, and dialogue. Speaker controls remain visible, and the canvas shows the dialogue. Use `画面外・ナレーション（尾なし）` for off-panel voices or narration. A visible speaker must also be included among that panel's characters. Click **変更を保存して閉じる** to save and close.
5. Press the normal **Run** button. P-H3 uses the empty-balloon guide (`<Picture 1>`) and character references (`<Picture 2–4>`), saves an unlettered PNG, then adds font-rendered lettering.
6. This is the generation workflow. Changing balloon placement, speakers, or scenes and running it again also updates the artwork with P-H3. For dialogue-only changes, use the separate workflow below.

`SaveImage` saves unlettered PNGs as `PH3_Manga/raw_*.png` under ComfyUI's output directory. Use this unlettered PNG when revising dialogue.

### Revise dialogue only (without P-H3)

1. Open **`02_letter_existing_page.json`**.
2. Load the saved **unlettered PNG** in `LoadImage`.
3. Edit the text regions and dialogue in `Create Bounding Boxes`. Each box's `text` is the dialogue to render.
4. Press the normal **Run** button. This workflow contains no model loaders, samplers, or P-H3 nodes; it only loads the page, renders lettering, and saves the result.

Use the unlettered PNG: loading an already-lettered image also retains its old text. The legacy `PH3MangaPage`, `PH3MangaPanel`, and `PH3MangaBalloonGuide` nodes remain available for compatibility.

### Tail tips and text regions

In the new editor, drag inside a balloon to move it, drag the bottom-right **□** to resize it, and drag the blue **●** to move the tail tip. Use **尻尾を短い初期位置に戻す** to shorten a tail, or toggle **尻尾を付ける** to add/remove it. Moving a balloon also moves its tail.

After generation, adjust lettering regions in `Create Bounding Boxes` in `02_letter_existing_page.json`. To change the balloons or tails themselves, return to the generation workflow and regenerate the artwork.

When using the legacy `Balloon Guide` node, specify each tail tip in the box's `desc` field using normalized coordinates over the entire page:

```json
{"tail": [500, 400]}
```

The order is `[x, y]`, the origin is the top-left corner, and coordinates range from 0 to 1000. Use `{}` or `{"tail": null}` for a tailless balloon. When using the legacy nodes, update tail coordinates after moving a panel or balloon.

`Balloon Guide` uses `inner_ratio` to define the text area inside each ellipse and `line_width` for the input guide's outline. Initial JSON accepts pixel-space `{x,y,width,height,metadata}` boxes or standard `{bbox,text,type,desc}` elements. An element's `bbox` uses **0–1000 `[ymin,xmin,ymax,xmax]`** coordinates, which have a different ordering from tail coordinates.

### Lettering and ruby

- A box's `text` is its dialogue. Explicit line breaks become vertical column boundaries and are retained. Without explicit breaks, BudouX segments phrases for automatic wrapping.
- `font_size` caps the font size as a fraction of page height. Text shrinks to fit its region.
- `ruby` is a JSON mapping from words to readings. Readings are drawn to the right of matching words.

```json
{"雨": "あめ", "一緒": "いっしょ"}
```

A ruby word must stay in a single column; a word split across columns will not receive its reading. Typesetting is intentionally basic and does not cover all publication typography rules, complex punctuation, or Latin-script layout.

This workflow does not repair or redraw balloons on a completed P-H3 output. If generation changes the guide's geometry, revise the input guide/prompt or adjust text regions to the generated artwork.
