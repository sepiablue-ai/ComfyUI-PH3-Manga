# ComfyUI-PH3-Manga

参照画像のキャラクターで漫画ページを描き、吹き出しの配置から日本語の写植までをComfyUIのワークフローで行うカスタムノードです。

## できること

- **コマ割りを見本画像から選ぶ**：2〜6コマ、196種類の空コマ割りを同梱しています。コマ数・種類・名前で絞り込め、お気に入りも登録できます。選ぶとコマの場面ノードが自動で増減し、減らしたコマの入力は退避して、戻すと復元します。
- **人物（最大3人）とコマごとの内容から漫画を生成する**：コマごとに場面（英語）と登場人物を入れると、P-H3への指示文を組み立てます。
- **セリフ・話者・吹き出し・尻尾を一画面で編集する**：セリフの入力先は一か所です。吹き出しの移動・拡大縮小と、尻尾の先端のドラッグに対応します。空の吹き出しを描いたガイドを生成モデルへの入力にします。
- **日本語を縦書きで写植する**：セリフ、明示した改行、ルビ、縦書きの句読点、簡易禁則、`！？` などの縦中横に対応します。かなと漢字に別々のフォントを指定できます。
- **作画を維持して写植をやり直す**：別の写植専用ワークフローで、保存した文字なしPNGへ写植します。写植専用ワークフローにはP-H3ノードを含めていません。

写植はフォントによる文字描画です。セリフとルビはP-H3やMOSSが生成する文字ではありません。吹き出しガイドも入力用の図形です。P-H3が最終的に描く吹き出しの形・位置やキャラの一致を保証するものではありません。

## 導入方法

### 1. ComfyUIを用意する

[ComfyUI](https://github.com/Comfy-Org/ComfyUI) のP-H3-Image対応版を使用してください。生成例には `PH3ImageConditioning` と `MiniMaxH3SigmaShift` が必要です。既存ページへの写植例では `CreateBoundingBoxes` を使用します。ノードが不足する場合は、既存環境を保護したうえでComfyUIを更新してください。

### 2. カスタムノードを配置する

このリポジトリのフォルダを `ComfyUI/custom_nodes/ComfyUI-PH3-Manga` として配置します。別の `ComfyUI-MossPanelDataset` の導入は不要です。

**ComfyUIを実行しているPython環境**で、次を実行してください。システム全体のPythonへインストールする必要はありません。

```bash
python -m pip install -r ComfyUI/custom_nodes/ComfyUI-PH3-Manga/requirements.txt
```

ComfyUI同梱のPythonを使う構成では、`python` をその実行ファイルに読み替えてください。追加依存のBudouXは日本語の文節区切りに使います。PyTorch・NumPy・PillowはComfyUIの環境を使用します。

### 3. 日本語フォントを用意する

写植に使用する日本語フォントを本パッケージの `fonts/` に置きます。利用権のある `.ttf`・`.ttc`・`.otf`・`.otc` を使用してください。[Noto CJK](https://github.com/notofonts/noto-cjk) などを利用できます。フォントファイル自体は同梱していません。

`kana_font` と `kanji_font` は、`auto` なら同梱用フォルダとインストール済みの日本語フォントから選択します。Windowsではインストール済みの游明朝・游ゴシックも候補になります。固定した組版が必要な場合は、両方に同じフォントファイル名を明示してください。別ディレクトリを探す場合は `PH3_MANGA_FONT_DIR` も指定できます。

### 4. P-H3のモデルを配置する

漫画生成を使う場合は、[PrunaAI/P-H3-Image-Comfy](https://huggingface.co/PrunaAI/P-H3-Image-Comfy) からモデルを用意します。同梱の生成例は次のファイル名を使用します。

| 種類 | 配置先（ComfyUIからの相対パス） | ファイル名 |
|---|---|---|
| 本体 | `models/diffusion_models/` | `p-h3-image_int8_convrot.safetensors` |
| テキストエンコーダー | `models/text_encoders/` | `p-h3-image_text_encoder_int8_convrot.safetensors` |
| VAE | `models/vae/` | `p-h3-image_vae_int8_convrot.safetensors` |

別の対応精度を使用する場合は、各ローダーで手元のファイルを選び直してください。この例はLoRA込みのP-H3本体を使い、プロンプト拡張モデルは使用しません。**既存ページへの写植だけなら、P-H3モデルは不要です。**

### 5. 再起動してワークフローを開く

ComfyUIを再起動してブラウザーを再読み込みし、`example_workflows/` のJSONを画面へドラッグしてください。

| ワークフロー | 用途 |
|---|---|
| [01_generate_and_letter.json](example_workflows/01_generate_and_letter.json) | 人物の画像（最大3人）とコマごとの場面・セリフから、空吹き出し付きの漫画を生成し、写植する（例は3コマ・2人） |
| [02_letter_existing_page.json](example_workflows/02_letter_existing_page.json) | 自分で用意した漫画ページへ、セリフとルビを写植する |

キャラ画像・入力ページは同梱していません。各 `LoadImage` で利用する画像をアップロードしてください。

以前の統合編集版を開いている場合は、必要な入力を保存し、ブラウザーを `Ctrl+F5` で再読み込みしてから、更新した `01_generate_and_letter.json` を開いてください。今回の版は、生成用とセリフ修正用のワークフローを分けています。

## 使い方

### 生成してから写植する

ワークフローは、①入力、②P-H3で作画、③保存と写植の3つの枠に分かれています。

1. **① 入力**：「人物1の画像」「人物2の画像」に参照キャラをアップロードします。3人目を使うときは `LoadImage` を足して「場面・登場人物を生成の指示にまとめる」の `人物3` へつなぎます（人物2があるときだけ使えます）。
2. **漫画の編集** ノードの **画像からコマ割りを選ぶ** で見本を選びます。コマ数に合わせて場面ノードが増減します。
3. 各コマの場面ノードに `場面`（英語）と `登場人物` を入力します。人物を `人物1` `人物2` `人物3` と書くと、P-H3が読める `the character from <Picture N>` に置き換わります。このノードにはセリフ欄はありません。
4. 同じノードから吹き出し編集画面を開き、吹き出しごとにコマ・話者・セリフを指定します。話者の選択欄は常に表示され、入力したセリフもキャンバス内で確認できます。画面外の声やナレーションは `画面外・ナレーション（尾なし）` を選びます。話す人物は、そのコマの登場人物にも入れてください。編集後は **変更を保存して閉じる** を押します。
5. 通常の **実行** を押すと、空吹き出しガイド（`<Picture 1>`）と参照画像（`<Picture 2〜4>`）から漫画を生成し、文字なしPNGを保存してからフォントで写植します。
6. このワークフローは通常生成用です。配置・話者・場面などを変更して再実行すると、P-H3で作画も更新します。セリフだけを直す場合は、下の専用ワークフローを使ってください。

文字なしPNGは `SaveImage` により、ComfyUIの出力先の `PH3_Manga/raw_*.png` に保存します。セリフの修正には、この文字なしPNGを使ってください。

### セリフだけを修正する（P-H3は使わない）

1. **`02_letter_existing_page.json`** を開きます。
2. `LoadImage` に、保存した **文字なしPNG** を読み込みます。
3. `Create Bounding Boxes` で文字領域とセリフを編集します。枠の `text` が写植する本文です。
4. 通常の **実行** を押します。このワークフローにはモデル・サンプラー・P-H3ノードがなく、画像の読み込みと写植・保存だけを行います。

既に文字を入れた画像を読み込むと古い文字も残るため、文字なしPNGを使ってください。旧 `PH3MangaPage`・`PH3MangaPanel`・`PH3MangaBalloonGuide` は互換性のため残しています。

### 吹き出しの尾と文字領域

新しい編集画面では、吹き出し内のドラッグで移動、右下の **□** で拡大縮小、青い **●** で尻尾の先端を移動します。**尻尾を短い初期位置に戻す**、**尻尾を付ける** の切り替えも使えます。吹き出しを動かすと尻尾も一緒に動きます。

生成後の文字領域は `02_letter_existing_page.json` の `Create Bounding Boxes` で調整します。吹き出しや尻尾そのものを変更する場合は、生成用ワークフローへ戻って作画をやり直してください。

旧 `Balloon Guide` を使う場合は、各枠の `desc` に、ページ全体を0〜1000にした座標で尾の先端を指定します。

```json
{"tail": [500, 400]}
```

順番は `[x, y]`、原点は左上です。尾のない吹き出しは `{}` または `{"tail": null}` にします。旧ノードでコマや吹き出しを動かした後は尾の座標も調整してください。

`Balloon Guide` の `inner_ratio` は楕円の内側で文字に使う範囲、`line_width` は入力ガイドの線幅です。初期JSONにはピクセル単位の `{x,y,width,height,metadata}` または標準の要素形式 `{bbox,text,type,desc}` を使用できます。要素形式の `bbox` は **0〜1000の `[ymin,xmin,ymax,xmax]`** で、尾とは座標の並びが異なります。

### 写植とルビ

- 枠の `text` が描画するセリフです。明示した改行は縦書きの列の区切りになり、そのまま保持します。改行を入れない場合はBudouXで文節を区切って自動的に折り返します。
- `font_size` はページ高さに対する文字サイズの上限です。枠に収まらない場合は縮小します。
- `ruby` に語句と読みのJSON対応表を入力すると、対応する語の右にルビを添えます。

```json
{"雨": "あめ", "一緒": "いっしょ"}
```

ルビを付ける語は同じ列に収めてください。改行や自動折り返しで語が列をまたぐと、その語のルビは付きません。組版は簡易的なもので、複雑な縦書き約物・欧文・出版用の完全な組版規則を網羅するものではありません。

文字なしのP-H3出力を編集して吹き出しを描き直す処理はありません。ガイドが生成結果で変形した場合は、入力ガイドやプロンプトを見直すか、文字領域を生成結果に合わせて調整してください。
